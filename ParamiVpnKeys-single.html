🔑 Parami VPN Keys

တခြား site ကမဟုတ်ဘဲ ကိုယ်ပိုင် site နဲ့ V2Ray / SSH / Shadowsocks / Outline key ထုတ်မယ်။

အရေးကြီးဆုံး အချက်
Site က key ထုတ်ပေးရုံပဲ။ တကယ် ချိတ်ဖို့က server တစ်လုံး လိုတယ်။ Server မှာ အဲဒီ UUID/password နဲ့ ကိုက်တဲ့ config run ထားမှ key က အလုပ်လုပ်မယ်။ Server မရှိတဲ့ key က ချိတ်လို့မရဘူး။

ဒီ site က ဘာကိုမှ server ကို မပို့ဘူး။ Key တွေက ဒီ browser ထဲမှာပဲ သိမ်းပါတယ်။ QR ထုတ်ဖို့ အပြင် QR server ကို key ပို့တာမျိုး မလုပ်ထားဘူး။

၁။ Key ထုတ်မယ်

VMess က အပေါ်က UUID, Security, Network, Host, Path, SNI ကိုပဲ သုံးပါတယ်။

Trojan က အပေါ်က Password, Security, Network, Host, Path, SNI ကိုပဲ သုံးပါတယ်။

အပေါ်က Password field (Shadowsocks အပိုင်းမှာ ပေါ်ပါတယ်) ကိုပဲ သုံးပါတယ်။

SSH က link မဟုတ်ဘူး။ Flâsh VPN → ထည့်ရန် → SSH form မှာ အောက်က အတိုင်း ဖြည့်ပါ။

မှတ်ချက်: VMess/Trojan/SSH form တွေမှာ UUID/Password field တစ်ခုတည်းကို မျှသုံးထားပါတယ်။ VLESS မှာ UUID ထုတ်ပြီးရင် VMess ပြောင်းလည်း အတူတူ UUID ပဲ သုံးလို့ရတယ်။


၂။ ငါ့ Keys + Subscription

Flâsh VPN ထဲမှာ: ထည့်ရန် → Link ကူးထည့်မှာ link တစ်ခုချင်း ကပ်တာက အသေချာဆုံးပါ။ Subscription text ကို base64 ဖြေပြီး link တွေ ပြန်ထုတ်ဖို့ site ပေါ်က Copy လုပ်ပြီးမှ သုံးပါ။

၃။ VPS မရှိရင် ဘာသုံးမလဲ? (အစားထိုး ၄ မျိုး)

ရိုးရိုးအမှန်: တခြားသူတွေအတွက် 24/7 ပေးချင်ရင် တစ်ခုခုတော့ အမြဲဖွင့်ထားရမယ်။ ဖွင့်ထားမယ့်အရာ မရှိဘဲ 24/7 မရဘူး။ VPS မရှိရင် အောက်က တစ်ခုခုက အဲဒီနေရာကို ယူတယ်။

အကောင်းဆုံး အစားထိုး: အိမ်က Router (ဖုန်းဖွင့်ထားစရာ မလို)

Router က မူလကတည်းက 24/7 ဖွင့်ထားပြီးသားပါ။ ဒါက မင်းရဲ့ စံနှုန်း — ဖုန်းဖွင့်ထားစရာ မလို၊ ကိုယ်ပိုင်စက်ပဲ — နဲ့ အကိုက်ဆုံးပါ။

  1. Router admin page ဖွင့်ကြည့်: VPN Server / WireGuard / OpenVPN ဆိုတာ ပါလား စစ်ပါ။ Asus, TP-Link, MikroTik တချို့မှာ ပါပြီးသား။
  2. WireGuard server ပါရင် အဲဒါက အလွယ်ဆုံးပါ။ Flâsh VPN က WireGuard .conf ထည့်လို့ရတယ်။
  3. OpenWrt တင်လို့ရတဲ့ router ဆိုရင် Shadowsocks / Xray ကို router ပေါ်မှာတင် run လို့ရတယ်။
  4. ISP က ပေးတဲ့ router မှာ VPN server မပါရင်၊ အဲဒီ router ကို ပြောင်းလို့မရရင် အောက်က Tunnel နည်းကို သုံးပါ။

အိမ်က internet က CGNAT ဖြစ်နေရင် router ကို အပြင်က တိုက်ရိုက် ချိတ်လို့မရဘူး။ အဲဒီအခါ Tunnel နည်း လိုတယ်။

ကိုယ်တိုင်စမ်းဖို့: ဖုန်း on-demand (24/7 host အတွက် မဟုတ်)

Termux ထဲမှာ Shadowsocks / Xray run ပြီး ကိုယ်တိုင် ချိတ်စမ်းလို့ရတယ်။ ဒါက မင်းအရင်ပြောခဲ့တဲ့အတိုင်းပဲ: ဖုန်းဖွင့်ထားရမယ်ဆိုရင် Termux နဲ့ပဲ လုပ်လိုက်တာက ပိုရိုးတယ်။

  1. Termux ဖွင့် → scripts/termux-quick.sh ကို ကြည့်။
  2. ဖုန်းနဲ့ တူတဲ့ WiFi ထဲက စက်တွေပဲ ချိတ်လို့ရမယ် (ဒါမှမဟုတ် Tunnel နဲ့ အပြင်ထုတ်ရမယ်)။
  3. ဖုန်းပိတ်ရင် / အိပ်သွားရင် server ရပ်သွားမယ်။ တခြားသူတွေအတွက် 24/7 မပေးနိုင်ဘူး။ ဒါကို host လုပ်တယ်လို့ မပြောပါနဲ့။

CGNAT ကို ကျော်ဖို့: Cloudflare Tunnel + အိမ်စက်

ထိုင်းဖုန်း carrier CGNAT လို၊ အိမ် internet ကလည်း public IP မပေးရင် အပြင်က တိုက်ရိုက် ဝင်လို့မရဘူး။ Cloudflare Tunnel က အိမ်စက်ကနေ အပြင်ကို ချိတ်ထွက်ပြီး domain တစ်ခုနဲ့ ပြန်ဝင်လို့ရအောင် လုပ်ပေးတယ်။

  1. အမြဲဖွင့်ထားမယ့် စက် လိုတယ်: router, mini PC, Raspberry Pi, ဒါမှမဟုတ် အဟောင်းဖုန်း။ Main ဖုန်း မဟုတ်တာက ပိုကောင်းတယ်။
  2. အဲဒီစက်မှာ cloudflared tunnel run ပြီး ကိုယ့် domain နဲ့ ချိတ်ပါ။
  3. Tunnel က website / panel အတွက် အကောင်းဆုံးပါ။ VPN traffic အတွက်တော့ TCP/WebSocket ပုံစံ (VLESS WS) နဲ့မှ အဆင်ပြေနိုင်တယ်။ UDP WireGuard ကို Tunnel နဲ့ တိုက်ရိုက် မသယ်နိုင်ဘူး။
  4. အဲဒီစက် ပိတ်ရင် အားလုံး ရပ်တယ်။

သတိ: Cloudflare Workers ကို VPN endpoint အဖြစ် ပြန်မသုံးပါနဲ့။ အရင် Edge VLESS-WS တွေ 1101 နဲ့ သေဖူးတယ်။ Tunnel က Workers မဟုတ်ဘူး၊ ဒါပေမဲ့ VPN အတွက် Cloudflare ရဲ့ စည်းမျဉ်းကို ချိုးဖောက်မိမလား ဆိုတာ ကိုယ့် domain / account နဲ့ စစ်ပြီးမှ လူအများအတွက် ဖွင့်ပါ။

နောက်ဆုံး အရန်နည်း: Free Cloud (VPS အမျိုးအစားပဲ၊ ဒါပေမဲ့ ဝယ်စရာမလို)

ဒါက တကယ်တော့ VPS ပဲ။ ဒါပေမဲ့ လောလောဆယ် VPS မရှိဘူးဆိုရင်၊ hardware မဝယ်ဘဲ 24/7 အတွက် အမြန်ဆုံး နည်းပါ။

  • Oracle Always Free, Google / AWS free tier လိုမျိုးတွေမှာ အခမဲ့ VM ရနိုင်တယ်။ Card verification တောင်းတတ်တယ်၊ idle ဖြစ်ရင် ပြန်သိမ်းနိုင်တယ်။
  • ဒါက မင်းအရင် ငြင်းခဲ့တဲ့ အချက်နဲ့ တိုက်ဆိုင်တယ်: စက်က သူများဟာ ဖြစ်သွားမယ်။ Site နဲ့ key က ကိုယ်ပိုင်ပေမဲ့ server စက်က ကိုယ်ပိုင်မဟုတ်ဘူး။
  • ဒါကြောင့် ဒါကို အမြဲတမ်း ဖြေရှင်းချက်လို့ မမှတ်ပါနဲ့။ Router / ကိုယ်ပိုင်စက် ရတဲ့အခါ အဲဒီကို ပြောင်းပါ။

၄။ Flâsh VPN နဲ့ ကိုက်ညီမှု

  • VLESS: public server မှာ security=none ဆို Flâsh ရဲ့ Xray core က ငြင်းတယ်။ TLS သုံးပါ။
  • Shadowsocks / Outline: ss:// link ကို Flâsh ထဲ ကူးထည့်လို့ရတယ်။ Outline က ss + outline=1 ပုံစံပါ။
  • SSH: Flâsh ထဲမှာ SSH form မှာ Host/Port/User/Pass ဖြည့်ရတယ်။ Link ပုံစံ မဟုတ်ဘူး။
  • Server config: site က ထုတ်တဲ့ UUID/password နဲ့ server ပေါ်က config တူရမယ်။ တူမှ ချိတ်မယ်။

၅။ ဒီ site ကို ဘယ်လို တင်မလဲ

ဒါက static site ပဲ (HTML + JS)။ Backend မလို။ GitHub Pages, Cloudflare Pages, ဒါမှမဟုတ် အိမ်စက် / router ပေါ်က web server မှာတင် တင်လို့ရတယ်။ DEPLOY.md ကို ကြည့်ပါ။
ပြည်သူအားလုံး မြင်နိုင်တဲ့ site အဖြစ် တင်ရင်၊ တကယ့် server password တွေ မထည့်ပါနဲ့။ Key ထုတ်ဖို့ပဲ သုံးပြီး server config ကို သီးသန့် လုပ်ပါ။
